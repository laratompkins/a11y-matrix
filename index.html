Color Contrast Matrix

The matrix displays contrast ratios and their WCAG compliance levels (AAA, AA, or Fail) and is preloaded with colors from the College of DuPage brand palette. To create your own palette, clear the matrix by selecting "Clear List". Select colors using the color picker or eyedropper tools, then select "Add to List". Hex codes can also be pasted directly into the input field with one hex code per line. After you have added your colors, select "Generate Matrix" to regenerate the contrast matrix using the list.
